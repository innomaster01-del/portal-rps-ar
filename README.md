# פורטל אבן נייר ומספריים 🌀✊✋✌️

משחק AR לאנדרואיד. כל שחקן מציב פורטל קטן על השולחן ומכניס אליו יד.
היד שלו יוצאת מהפורטל של היריב, בבית אחר. הטלפון מזהה אבן, נייר או מספריים וקובע מי ניצח.

## הורדה

**[להורדת ה-APK האחרון](../../releases/latest)**: מורידים בטלפון, פותחים ומאשרים התקנה ממקור לא מוכר.

אפשר גם לשחק בלי להתקין: https://innomaster01-del.github.io/portal-rps-ar/

### דרישות
- אנדרואיד עם תמיכה ב-ARCore (רוב הטלפונים מ-2019 והלאה)
- Google Chrome מעודכן. האפליקציה רצה בתוך Chrome, כי רק בו יש WebXR (AR) וגישה למצלמה של ה-AR.

## איך משחקים
1. שחקן אחד לוחץ "צור חדר" ושולח לשני את הקישור או את הקוד.
2. כל אחד לוחץ "הפעל AR" ומציב פורטל על שולחן.
3. מכניסים יד לפורטל. כשהידיים של שניכם בפנים מתחילה ספירה: אבן… נייר… ומספריים!
4. הטלפון של מי שיצר את החדר הוא השופט, והתוצאה מופיעה אצל שניכם.

יש גם מצב "שחק נגד המחשב", וכפתורי 🪨📄✂️ למי שאין לו זיהוי יד.

## איך זה בנוי
| תיקייה | מה יש בה |
|---|---|
| `web/` | המשחק עצמו: three.js עם WebXR, זיהוי יד ב-MediaPipe, וחיבור בין הטלפונים ב-PeerJS (WebRTC) |
| `android/` | אפליקציית Trusted Web Activity שפותחת את המשחק ב-Chrome על כל המסך |
| `.github/workflows/build.yml` | בכל push ל-main: מעלה את `web/` ל-GitHub Pages, בונה APK חתום ומפרסם אותו ב-Releases |

## הגדרה חד-פעמית
1. **GitHub Pages:** ב-Settings → Pages → Source בוחרים **GitHub Actions**.
2. **מפתח חתימה קבוע:** ב-Settings → Secrets and variables → Actions מוסיפים `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
   בלי המפתח, ה-APK נחתם במפתח זמני שמשתנה בכל בנייה, ואז אי אפשר לעדכן את האפליקציה בלי להסיר אותה קודם.
3. **מסך מלא, בלי שורת הכתובת של Chrome:** Chrome צריך לוודא שהאתר והאפליקציה שייכים לאותו בעלים. הוא מחפש את הקובץ בשורש הדומיין, בכתובת
   `https://innomaster01-del.github.io/.well-known/assetlinks.json`.
   לכן צריך ריפו בשם `innomaster01-del.github.io` עם הקובץ `extras/.well-known/assetlinks.json` מכאן, ועם קובץ ריק בשם `.nojekyll` בשורש הריפו.
   עד שזה מוגדר, האפליקציה עובדת, רק עם שורת כתובת קטנה למעלה.
