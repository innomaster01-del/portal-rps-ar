# פורטל אבן נייר ומספריים 🌀✊✋✌️

משחק AR לאנדרואיד, אפליקציה נייטיב מלאה. כל שחקן מציב פורטל קטן על השולחן ומכניס אליו יד.
היד שלו יוצאת מהפורטל של היריב, בבית אחר. הטלפון מזהה אבן, נייר או מספריים וקובע מי ניצח.

## הורדה
**[להורדת ה-APK האחרון](../../releases/latest)**: מורידים בטלפון, פותחים ומאשרים התקנה ממקור לא מוכר.

דרישות: טלפון אנדרואיד 8 ומעלה שתומך ב-ARCore. בפעם הראשונה הטלפון אולי יבקש להתקין את Google Play Services for AR.

## איך משחקים
1. שחקן אחד פותח "⚙️ חדר", לוחץ "צור חדר" ושולח לשני את הקוד. השני מקליד את הקוד ולוחץ "הצטרף".
2. כל אחד מכוון את הטלפון לשולחן ומקיש על המסך כדי להציב פורטל.
3. מכניסים יד לפורטל. כשהידיים של שניכם בפנים מתחילה ספירה: אבן… נייר… ומספריים!
4. הטלפון של מי שיצר את החדר הוא השופט, והתוצאה מופיעה אצל שניכם.

יש גם מצב "שחק נגד המחשב", ואפשרות לשחק עם כפתורים במקום זיהוי יד.

## איך זה בנוי
| קובץ | מה הוא עושה |
|---|---|
| `MainActivity.java` | מסך, ARCore (משטחים ועוגן לפורטל), חוקי המשחק |
| `SceneRenderer.java`, `Mesh.java` | ציור ב-OpenGL: תמונת המצלמה, הפורטל, היד המצוירת |
| `HandTracker.java` | זיהוי יד ב-MediaPipe על תמונת המצלמה של ARCore, ומיקום היד בתלת-ממד |
| `HandMath.java` | חישובים: מיקום היד, זיהוי אבן/נייר/מספריים, מי ניצח |
| `Net.java` | חיבור בין שני הטלפונים דרך שרת MQTT ציבורי (broker.hivemq.com) |
| `web-prototype/` | אב-הטיפוס הראשון, בדפדפן. לא בשימוש באפליקציה |

בכל push ל-main, GitHub Actions בונה APK חתום ומפרסם אותו ב-Releases.

## מפתח חתימה קבוע
ב-Settings → Secrets and variables → Actions מוסיפים `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
בלי המפתח, ה-APK נחתם במפתח זמני שמשתנה בכל בנייה, ואז אי אפשר לעדכן את האפליקציה בלי להסיר אותה קודם.

## פרטיות
מיקומי האצבעות (21 נקודות) ותוצאות המשחק עוברים בין הטלפונים דרך שרת ציבורי, בערוץ לפי קוד החדר. וידאו מהמצלמה לא נשלח לשום מקום.
